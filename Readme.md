# 🎨 Colour Matching Tool

A simple and interactive web application built with **Python and Streamlit** for colour matching and colour analysis.

The application allows users to select a colour and view:

- HEX colour value
- RGB colour value
- HSL colour value
- Closest matching colour names
- Colour similarity percentage
- Complementary colour
- Analogous colours
- Triadic colours
- Lighter and darker variations
- Built-in colour database

---
